Release History

About

Lightweight multi-tab GUI terminal wrapper with clipboard image paste support. Works with any CLI tool — Claude Code, Codex, and more.

Usage

  • Click + or press Cmd/Ctrl+T to open a new session
  • Paste screenshots with Cmd/Ctrl+V — preview appears above terminal
  • Drag & drop files into window to attach
  • Press Enter to send with file path auto-attached
  • Cmd/Ctrl+W close tab (confirms first), Ctrl+Tab switch tabs

Keyboard Shortcuts

Cmd/Ctrl+TNew tab Cmd/Ctrl+WClose tab (confirms first) Ctrl+TabNext tab Cmd+]/[ · Ctrl+PgDn/PgUpNext / Prev tab (mac · win) Cmd/Ctrl+VPaste image Ctrl+CCopy selection (win; no selection = interrupt) Shift+EnterNewline (no submit) Cmd/Ctrl+,Settings
